## 🔄 How Does It Work?

Without getting too technical, here’s a simple breakdown:

- **Unicode Sanitization:** AI tools sometimes insert special invisible characters (like zero-width spaces) to mark text. This tool finds and removes them.
- **Statistical Rewriting:** Some generators create text patterns that statistical models can detect. The tool adjusts phrasing slightly to break those patterns.
- **C2PA Removal:** Modern cameras and AI tools embed cryptographic certificates. The tool identifies and deletes these from the file structure.
- **Metadata Wiping:** This removes basic info like author name, creation date, and software used to create the file.

The result is a file that looks identical to you but is completely "clean" to detection systems.
